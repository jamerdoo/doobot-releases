# DooBot NG · Descargas

Aquí se publican los instaladores de **DooBot NG**, el bot para Minibia.

1. Entra en **[Releases](../../releases/latest)** y descarga `DooBotNG-x.y.z.msi`.
2. Instálalo (no pide permisos de administrador).
3. Si Windows muestra «Windows protegió su PC», pulsa **Más información → Ejecutar de todas formas**.
4. Abre DooBot NG, pega tu clave de licencia (`DBN1-XXXX-XXXX-XXXX-XXXX`) y pulsa **Activar**.
   La clave queda vinculada a tu PC y no funciona en otro equipo.

El bot se actualiza solo: cuando haya una versión nueva te aparecerá en la pestaña **Novedades**.
